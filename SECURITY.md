# Security Policy

## Supported Versions

Security fixes are considered for the latest released version of `pysteer`.

## Reporting a Vulnerability

Please do not open a public issue for a vulnerability.

Report security concerns through GitHub private vulnerability reporting if it is
enabled for the repository, or contact the maintainer listed in `pyproject.toml`.
Include:

- A description of the issue.
- Steps to reproduce it.
- The affected version or commit.
- Any known mitigations.

The maintainer will acknowledge valid reports and coordinate a fix before
public disclosure when appropriate.
